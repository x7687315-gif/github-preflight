# 决策简报模板（选项优先）

> **主产物是"选项"**：把检索到的方案整理成若干**可选方向**，连同**原文链接**交给用户拍板——让用户选走哪条路，而不是替他下结论。
> 完整报告是**可选落盘**（工程进行中的小决策用"快速核查"即可，不必写成 MD）。
> **硬性要求：§0 检索台账必须存在**——没有台账 = 视为没有真正检索。
> 凡"待验证"项，明确标出让用户后续确认。
